1. 项目基础架构
微信原生 TS 小程序环境搭建、无用 Demo 清理
目录分层规范：api /utils/types /store/assets /pages
全局 TS 类型统一约束（接口返回、用户、请求参数）
2. 缓存工具 utils/cache.ts
带过期时间本地存储封装
增、删、清空缓存全套方法，全局复用
3. 企业级请求拦截器 api/request.ts（核心亮点）
统一 baseUrl、全局 loading
token 401 并发锁无感刷新机制
全局错误统一提示
内置本地 Mock 模拟接口，无需后端即可调试
get/post 快捷请求方法封装
4. 用户接口层 api/user.ts
微信登录、刷新 token、获取用户信息接口封装
接口调用后自动存入全局状态
5. 全局状态管理 store/user.ts
内存 + 本地缓存双存用户信息
发布订阅 watch 监听用户状态变更
退出登录统一逻辑（清空缓存 + 页面跳转）
页面卸载取消订阅，解决内存泄漏
6. UI 基础引入
Vant Weapp 组件库安装、页面测试按钮可用
全局安全区兼容样式 global.wxss
7. 测试页面 pages/index
接口调用测试、用户信息展示、退出登录功能
验证请求、缓存、状态全套链路通断
8️⃣ 通用工具库 utils/common.ts（通用业务工具）
防抖、节流函数（搜索、上拉加载、滚动）
金额格式化、保留两位小数、元 / 分转换
时间格式化、时间戳转年月日、倒计时工具
图片压缩、手机号正则校验、表单校验通用方法
9️⃣ 分类横向滚动切换，切换防抖防止频繁请求；
商品分页加载、上拉触底增量渲染；
